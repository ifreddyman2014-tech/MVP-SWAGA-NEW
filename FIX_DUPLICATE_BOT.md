# 🔧 Исправление ошибки "Bot остановлен"

## 🔴 Проблема:
Бот постоянно показывает сообщение **"🛑 SWAGA VPN Bot остановлен"** и спамит в логах.

## 🎯 Причина:
Два systemd сервиса (`swaga-bot.service` и `vpnbot.service`) используют **один и тот же токен бота**. Когда один запускается, Telegram отключает другой, что вызывает shutdown handler и сообщение "Bot остановлен". Затем systemd автоматически перезапускает сервис, и цикл повторяется.

---

## ✅ Быстрое исправление (автоматически):

### На продакшн-сервере выполните:

```bash
# 1. Перейдите в директорию проекта
cd /root/MVP-SWAGA-NEW

# 2. Подтяните последние изменения
git pull origin claude/check-status-bH5rv

# 3. Запустите скрипт исправления
sudo ./fix_duplicate_bot.sh
```

Скрипт автоматически:
- ✅ Остановит и отключит дублирующий сервис `swaga-bot.service`
- ✅ Отключит старый `.env` файл в `/root/bot/`
- ✅ Остановит все конфликтующие процессы
- ✅ Запустит правильный сервис `vpnbot`
- ✅ Проверит что запущен только 1 процесс бота

## 🛠️ Ручное исправление (если нужно):

### Шаг 1: Остановить дублирующий сервис

```bash
systemctl stop swaga-bot.service
systemctl disable swaga-bot.service
```

### Шаг 2: Отключить старый .env

```bash
mv /root/bot/.env /root/bot/.env.disabled
```

### Шаг 3: Остановить все процессы бота

```bash
pkill -f "python.*bot.py"
pkill -f "python.*main.py"
```

### Шаг 4: Запустить правильный сервис

```bash
systemctl restart vpnbot
systemctl enable vpnbot  # если еще не включен
```

### Шаг 5: Проверить что запущен только 1 процесс

```bash
ps aux | grep bot.py | grep -v grep
```

**Должен быть только 1 процесс!**

### Шаг 6: Проверить логи

```bash
journalctl -u vpnbot -f
```

## 📊 Проверка после исправления:

### 1. **Проверить количество процессов:**
```bash
ps aux | grep -E "python.*bot.py|python.*main.py" | grep -v grep | wc -l
```
**Результат должен быть: 1**

### 2. **Проверить статус сервиса:**
```bash
systemctl status vpnbot
```
**Должно быть: active (running)**

### 3. **Проверить что нет сообщений "Bot остановлен":**
```bash
journalctl -u vpnbot -n 50 | grep "остановлен"
```
**Результат: ничего не найдено (это хорошо!)**

## 🚨 Если проблема повторяется:

### Проверьте все места где может быть токен:

```bash
# Найти все .env файлы
find /root -name ".env" -type f 2>/dev/null

# Проверить токены в найденных файлах
grep "BOT_TOKEN" /root/bot/.env 2>/dev/null
grep "BOT_TOKEN" /root/MVP-SWAGA-NEW/.env 2>/dev/null
```

**Токен должен быть только в одном месте:** `/root/MVP-SWAGA-NEW/.env`

### Проверьте все сервисы:

```bash
systemctl list-units --type=service | grep -E "swaga|vpn|bot"
```

**Должен работать только:** `vpnbot.service`
