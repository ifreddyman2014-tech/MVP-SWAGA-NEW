# Добавление новых серверов (us1, us2) для существующих пользователей

## 📋 Краткая информация

Этот документ описывает как добавить новые серверы США (us1, us2) в подписки всех существующих активных пользователей.

### Текущая ситуация
- 4 активных пользователя: 364044145, 1355248417, 6130546533, 6219793117
- 2 новых сервера: us1 (80.76.49.140) и us2 (31.57.38.104)
- Серверы уже настроены и работают (проверено вручную)
- Все скрипты готовы к запуску

## 🚀 Быстрый старт

### 1. Тестовый запуск (dry-run)

Сначала проверьте что будет сделано без реального выполнения:

```bash
python3 add_servers_to_existing_users.py --dry-run
```

Это покажет:
- Список активных пользователей
- На какие серверы будут добавлены
- Какие конфигурации будут созданы

### 2. Реальный запуск

Если dry-run показал правильные данные, запустите реальное добавление:

```bash
python3 add_servers_to_existing_users.py
```

Скрипт автоматически:
- ✅ Получит всех активных пользователей из БД
- ✅ Создаст конфигурации на us1 и us2 серверах
- ✅ Использует те же UUID и даты окончания подписок
- ✅ Пропустит пользователей, которые уже есть на сервере
- ✅ Сохранит информацию о добавлении в БД

## 🐛 Устранение проблем

### Проблема: "Connection closed" или "Timeout"

**Причина**: Proxy блокирует доступ к серверу

**Решение**: Запустите скрипт на машине с прямым доступом к серверам (не через Claude Code)

### Проблема: "Client already exists"

**Причина**: Клиент уже был добавлен ранее

**Решение**: Это нормально, скрипт пропустит таких пользователей

### Проблема: "Inbound X not found"

**Причина**: На сервере нет указанного inbound_id

**Решение**: Скрипт автоматически попытается использовать первый доступный inbound

### Проблема: "Authentication failed"

**Причина**: Неверные учетные данные в servers.json

**Решение**: Проверьте xui_username и xui_password для проблемного сервера

## 📝 Что делает скрипт технически

1. **Подключается к БД** (`subscriptions.db`)
2. **Извлекает активных пользователей** с их UUID и датами окончания
3. **Для каждого пользователя**:
   - Авторизуется на us1/us2 через API
   - Проверяет существующие inbound'ы
   - Создает клиента с теми же UUID и датой окончания
   - Email формата: `tg_{user_id}_{xui_sub_id}`
4. **Сохраняет информацию** в таблицу `user_servers`

## 🔐 API Endpoints

Скрипт автоматически пробует все известные endpoints:

### Для 3X-UI v2.8.x (новый стиль):
- `/panel/inbound/addClient`
- `/xui/inbound/addClient`
- `/api/inbound/addClient`

### Для 3X-UI v2.4.x (старый стиль):
- `/panel/api/inbounds/addClient`
- `/xui/api/inbounds/addClient`

Один из них обязательно сработает для вашей версии панели.
